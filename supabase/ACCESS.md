# Доступ к объектам (project_members)

## SQL
Выполните `supabase/migrations/20260316_project_members_access.sql`

## Правила
- **Руководитель (owner)** видит все объекты
- **Менеджер / прораб / клиент** — только объекты из «Команда объекта»
- При создании объекта создатель автоматически попадает в команду
- Backfill SQL даёт owner/manager доступ ко всем уже существующим объектам

## UI
На вкладке «Обзор» объекта — блок **Команда объекта** (добавить/убрать участников).
