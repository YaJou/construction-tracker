# СтройУчёт — учёт строительства

Минималистичное веб-приложение для учёта строительства домов по этапам: объекты, этапы, фото-отчёты, расходы и отчёты для руководителя/клиента.

## Стек

- **Next.js 15** (App Router)
- **React 18**
- **TailwindCSS**
- **Хранилище**: JSON-файл `data/store.json` (для MVP без нативных зависимостей; позже можно заменить на SQLite/PostgreSQL)
- **TypeScript**

## Запуск

```bash
# Установка зависимостей
npm install

# Создание БД и демо-данные (5 объектов, этапы, фото, расходы)
npm run db:seed

# Режим разработки
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

## Структура

- **Дашборд** — список объектов, поиск, фильтр по статусу, прогресс.
- **Объект** — карточка проекта, этапы (таймлайн), фото, расходы, журнал действий.
- **Отчёты** — формирование отчёта по объекту с экспортом в PDF (печать в PDF из браузера).

## Расширяемость

Архитектура позволяет добавить позже:

- учёт работников и материалов;
- календарь работ;
- уведомления;
- мультипользовательскую систему и роли (директор / менеджер / прораб).

Данные: `data/store.json`. Фото загружаются в `public/uploads/{projectId}/`. Для PDF отчёта откройте отчёт и нажмите «Печать» в браузере → «Сохранить как PDF».
